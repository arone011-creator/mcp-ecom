# M3 — MCP Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `apps/mcp/` — an MCP server exposing the nine tools in [tool-surface.md](../../mcp/tool-surface.md) over the existing `/api/v1` REST API, with high-risk calls enforced server-side, provable from a bare MCP client with no agent in existence.

**Architecture:** The MCP server is an adapter, never a second implementation. It calls `/api/v1` over HTTP with the caller's bearer token and re-implements no business rule — ownership, stock, and cancellation eligibility all stay in `apps/web`. Three gaps in the backend are closed first (identity echo, short-lived tokens, idempotency) because the MCP layer cannot be built correctly on top of their absence. Approval-token minting and validation live in the MCP server, which is the only caller of the high-risk path.

**Tech Stack:** Python 3.11+ (3.12.7 locally), FastMCP 2.x, httpx, Pydantic v2, pytest + respx. Web side: Next.js 15.5.6, Prisma 5.22, Jest. Deployed as a second Railway service in project `mcp_ecom` alongside `web`.

## Decisions Locked In This Plan

Three of these were flagged as blocking in [open-questions.md](../../mcp/open-questions.md). They are answered here with reasoning, so they can be overridden deliberately rather than drifted past.

**1. Identity comes from a new `GET /api/v1/auth/whoami`, not from decoding the JWT in Python.**

Phase 1 §1.5 says the MCP server "can verify the session token out-of-band using the same `NEXTAUTH_SECRET`". Verified against the installed package, that is more expensive than it sounds: NextAuth v4 does not sign a JWS, it **encrypts a JWE** — `new EncryptJWT(token).setProtectedHeader({ enc: 'A256GCM' })` with an HKDF-SHA256-derived key (`next-auth/jwt/index.js:41`, `:100`). Decrypting that in Python means a second implementation of NextAuth's key derivation, which is precisely the duplicated-rule failure the adapter principle exists to prevent — and it would silently break the day NextAuth changes its salt.

Instead the MCP server treats the token as opaque, forwards it, and asks the API who the caller is. One implementation of identity, in `requireApiUser`, exactly as [session.ts](../../../apps/web/app/api/v1/_lib/session.ts) intends.

**2. Approval tokens are minted and validated in the MCP server, not in `apps/web`.**

The web API's unit of identity is a user. Approval is about *this conversation turn wanting to call this tool with these arguments* — state that only exists in the MCP layer. Putting it in `apps/web` would push an agent-only concept into the storefront's API.

The honest limitation: this defends the *agent* path. Anyone holding a bearer token can still call `POST /api/v1/orders/{id}/cancel` directly. That is unchanged from today and is not what the approval token is for — the API's own defence is ownership plus status rules, which stay where they are. The approval token exists so that a **prompt-injected agent** cannot talk itself past a confirmation step, and it belongs where that agent's calls arrive.

**3. `remove_from_cart` is Medium.**

The unsettled row in tool-surface.md. Medium, by symmetry with `add_to_cart`: it is reversible (re-add the line), and `DELETE /api/v1/cart` scopes `deleteMany` to the caller's own cart id, so a `productId` from the query string can only ever reach the caller's own lines ([cart/route.ts](../../../apps/web/app/api/v1/cart/route.ts)). Task 12 writes this into tool-surface.md with the reasoning.

**4. Idempotency is database-backed, not in-process.**

The in-process fixed-window rate limiter was the right call for the token endpoint ([rate-limit.ts](../../../apps/web/app/api/v1/_lib/rate-limit.ts)) because losing its state on redeploy fails *safe* — a forgotten counter grants extra attempts to a password endpoint that has other defences. Idempotency fails the other way: a forgotten key means a retried `cancel_order` executes twice. A `Prisma` model costs one migration and makes the retry return the *original* response rather than a confusing 409.

## Prior Findings This Plan Depends On

Each verified by reading the code, not by trusting a document. Do not re-derive these; do check them if a task fights you.

- **Envelope.** Every v1 response is `{ data }` or `{ error }`, always with `cache-control: no-store`. `normalise()` converts Prisma `Decimal` to a **string** (`"10.50"` — deliberately not a float, to preserve scale) and `Date` to ISO 8601. [respond.ts](../../../apps/web/app/api/v1/_lib/respond.ts). **Pydantic models must type money as `str`, not `float`.**
- **Identity.** `requireApiUser` accepts a bearer token or a session cookie carrying the same NextAuth JWT. An explicit bearer wins over an ambient cookie, and a bearer that fails to decode is a hard `null` — never a silent downgrade to the cookie. Returns `{ id, email, role }`. [session.ts](../../../apps/web/app/api/v1/_lib/session.ts).
- **Token lifetime.** `TOKEN_MAX_AGE_SECONDS = 7 * 24 * 60 * 60` in [auth/token/route.ts:24](../../../apps/web/app/api/v1/auth/token/route.ts). These JWTs are stateless with **no revocation**; rotating `NEXTAUTH_SECRET` is the only kill switch and it signs out every browser.
- **Cart semantics.** `POST /api/v1/cart` takes `{ productId, quantity, mode? }`. `mode` defaults to `'add'` (increments an existing line); `'set'` replaces. Unknown modes are rejected rather than guessed. Unpublished products 404 exactly like absent ones. Over-stock is **409** with `Only N available; cart would hold M`. The response is the full cart view, so no follow-up GET is needed.
- **Cart view shape.** `{ items, itemCount, subtotal }` where `subtotal` is a fixed-2 **string**.
- **Order privacy.** `GET /api/v1/orders/{id}` returns 404 — not 403 — for someone else's order, and `cancel` maps `Unauthorized` to a 404 with the body `Order not found`, so neither route confirms an id exists. [orders/[id]/route.ts](../../../apps/web/app/api/v1/orders/[id]/route.ts), [cancel/route.ts](../../../apps/web/app/api/v1/orders/[id]/cancel/route.ts).
- **Cancel status codes.** 401 auth, 404 not-found/unauthorized, **409** `Order cannot be cancelled`, 500 failure. Only `PENDING` and `PROCESSING` are cancellable. [cancel-order.ts](../../../apps/web/server/orders/cancel-order.ts).
- **Products are public.** `GET /api/v1/products` and `/products/{id}` resolve no caller by design. `/products/{id}/inventory` is `force-dynamic` and never cached.
- **`sort=price` is always descending.** Ascending is unreachable. Do not advertise "cheapest first" in a tool description.
- **`searchProducts` sits behind a 300s `unstable_cache`.** M2's 89ms p95 for `/api/v1/products` is mostly cache hits. The M3 sweep must vary its queries or the baseline is fiction.
- **Test conventions.** Integration tests mock Prisma wholesale via `jest.mock('@/lib/prisma', ...)` and mock `requireApiUser` directly; they never touch a database. Follow that pattern — see [api-v1-cart.test.ts](../../../apps/web/tests/integration/api-v1-cart.test.ts).
- **Railway.** Service `web` builds with RAILPACK from `main`, root `/apps/web`, region `sin`, one replica. **A Dockerfile at a service's root directory silently flips the builder from RAILPACK to Docker.** Do not put one at `apps/mcp/`.

```ts
// app/api/v1/auth/whoami/route.ts
//
// GET /api/v1/auth/whoami -- the caller, as this API understands them.
//
// Exists for the MCP server. NextAuth v4 mints an encrypted JWE, not a
// signed JWS, so a non-JS client cannot read the subject out of a token
// without re-implementing NextAuth's HKDF key derivation. Rather than keep
// a second copy of that crypto in Python, the MCP server forwards the
// token it was given and asks here. One implementation of identity,
// the same one every other v1 route uses.
import type { NextRequest } from 'next/server';
import { requireApiUser } from '../../_lib/session';
import { ok, fail } from '../../_lib/respond';

export const runtime = 'nodejs';
export const dynamic = 'force-dynamic';

export async function GET(req: NextRequest) {
  const user = await requireApiUser(req);
  if (!user?.id) return fail(401, 'Authentication required');

  // Deliberately not the whole token: the MCP server needs to know who it
  // is acting for, not everything the session happens to carry.
  return ok({ id: user.id, email: user.email, role: user.role });
}
```

```ts
// tests/unit/token-ttl.test.ts
//
// The token endpoint's default is seven days, which is right for a human
// pasting a credential into a script and wrong for a token that will be
// handed to an agent. These JWTs have no revocation -- rotating
// NEXTAUTH_SECRET is the only kill switch, and it signs out every browser
// -- so the only lever that shortens exposure is the lifetime itself.
//
// Clamped rather than rejected: asking for a year and getting a week is
// safe, and so is asking for one second and getting sixty. Both directions
// fail towards a shorter, valid token.

import { clampTtl, DEFAULT_TTL_SECONDS, MIN_TTL_SECONDS } from '@/app/api/v1/auth/token/route';

describe('clampTtl', () => {
  it('defaults to seven days when unspecified', () => {
    expect(clampTtl(undefined)).toBe(DEFAULT_TTL_SECONDS);
    expect(DEFAULT_TTL_SECONDS).toBe(7 * 24 * 60 * 60);
  });

  it('honours a short lifetime', () => {
    expect(clampTtl(900)).toBe(900);
  });

  it('clamps below the floor up to the floor', () => {
    expect(clampTtl(1)).toBe(MIN_TTL_SECONDS);
    expect(clampTtl(0)).toBe(MIN_TTL_SECONDS);
    expect(clampTtl(-30)).toBe(MIN_TTL_SECONDS);
  });

  it('clamps above the ceiling down to the default', () => {
    expect(clampTtl(365 * 24 * 60 * 60)).toBe(DEFAULT_TTL_SECONDS);
  });

  it('ignores values that are not whole numbers of seconds', () => {
    expect(clampTtl(90.5 as unknown as number)).toBe(DEFAULT_TTL_SECONDS);
    expect(clampTtl('900' as unknown as number)).toBe(DEFAULT_TTL_SECONDS);
    expect(clampTtl(NaN)).toBe(DEFAULT_TTL_SECONDS);
  });
});
```

- [ ] **Step 3: Export the constants and the clamp**

In `apps/web/app/api/v1/auth/token/route.ts`, replace:

```ts
const TOKEN_MAX_AGE_SECONDS = 7 * 24 * 60 * 60;
```

with:

```ts
export const DEFAULT_TTL_SECONDS = 7 * 24 * 60 * 60;
// A minute is short enough to be useless to a leak and long enough that a
// slow first tool call does not expire mid-flight.
export const MIN_TTL_SECONDS = 60;

/**
 * Callers may ask for a shorter-lived token; the MCP server does. Anything
 * unusable -- absent, fractional, non-numeric, out of range -- falls back
 * to a valid lifetime rather than failing the exchange, because every
 * outcome here is still a token the caller can use, just for less time.
 */
export function clampTtl(requested: number | undefined): number {
  if (!Number.isInteger(requested)) return DEFAULT_TTL_SECONDS;
  const value = requested as number;
  if (value < MIN_TTL_SECONDS) return MIN_TTL_SECONDS;
  if (value > DEFAULT_TTL_SECONDS) return DEFAULT_TTL_SECONDS;
  return value;
}
```

```prisma
model IdempotencyKey {
  id          String   @id @default(cuid())
  key         String
  userId      String
  scope       String
  requestHash String
  status      Int      @default(0)
  response    Json?
  createdAt   DateTime @default(now())
```

Create `apps/web/tests/integration/api-v1-idempotency.test.ts`:

```ts
// tests/integration/api-v1-idempotency.test.ts
//
// A retry after a timeout must not do the thing twice. The claim row is
// taken before the work runs, so two identical requests race for a unique
// constraint rather than both executing.

const mockPrisma = {
  idempotencyKey: {
    create: jest.fn(),
    findUnique: jest.fn(),
    update: jest.fn(),
    delete: jest.fn(),
  },
};
jest.mock('@/lib/prisma', () => ({ __esModule: true, default: mockPrisma }));

import { NextResponse } from 'next/server';
import { withIdempotency, requestHash } from '@/app/api/v1/_lib/idempotency';

const USER = 'user_a';

function conflict() {
  // Prisma reports a unique-constraint violation as P2002.
  return Object.assign(new Error('Unique constraint failed'), { code: 'P2002' });
}

beforeEach(() => jest.clearAllMocks());

describe('withIdempotency', () => {
  it('runs the handler when no key header is present', async () => {
    const handler = jest.fn().mockResolvedValue(NextResponse.json({ data: 1 }));

    const res = await withIdempotency(null, USER, 'cart:add', { a: 1 }, handler);

    expect(handler).toHaveBeenCalledTimes(1);
    expect(res.status).toBe(200);
    expect(mockPrisma.idempotencyKey.create).not.toHaveBeenCalled();
  });

  it('claims the key before running the handler', async () => {
    const order: string[] = [];
    mockPrisma.idempotencyKey.create.mockImplementation(async () => {
      order.push('claim');
      return {};
    });
    const handler = jest.fn().mockImplementation(async () => {
      order.push('handler');
      return NextResponse.json({ data: 1 });
    });

    await withIdempotency('k1', USER, 'cart:add', { a: 1 }, handler);

    expect(order).toEqual(['claim', 'handler']);
  });

  it('stores the outcome so a retry can replay it', async () => {
    mockPrisma.idempotencyKey.create.mockResolvedValue({});
    const handler = jest
      .fn()
      .mockResolvedValue(NextResponse.json({ data: { itemCount: 2 } }));

    await withIdempotency('k1', USER, 'cart:add', { a: 1 }, handler);

    expect(mockPrisma.idempotencyKey.update).toHaveBeenCalledWith({
      where: { userId_scope_key: { userId: USER, scope: 'cart:add', key: 'k1' } },
      data: { status: 200, response: { data: { itemCount: 2 } } },
    });
  });

  it('replays a completed key without running the handler again', async () => {
    mockPrisma.idempotencyKey.create.mockRejectedValue(conflict());
    mockPrisma.idempotencyKey.findUnique.mockResolvedValue({
      requestHash: requestHash({ a: 1 }),
      status: 200,
      response: { data: { itemCount: 2 } },
    });
    const handler = jest.fn();

    const res = await withIdempotency('k1', USER, 'cart:add', { a: 1 }, handler);

    expect(handler).not.toHaveBeenCalled();
    expect(res.status).toBe(200);
    expect(await res.json()).toEqual({ data: { itemCount: 2 } });
    expect(res.headers.get('idempotent-replay')).toBe('true');
  });

  it('refuses a key reused with different arguments', async () => {
    mockPrisma.idempotencyKey.create.mockRejectedValue(conflict());
    mockPrisma.idempotencyKey.findUnique.mockResolvedValue({
      requestHash: requestHash({ a: 1 }),
      status: 200,
      response: { data: 1 },
    });
    const handler = jest.fn();

    const res = await withIdempotency('k1', USER, 'cart:add', { a: 2 }, handler);

    expect(handler).not.toHaveBeenCalled();
    expect(res.status).toBe(409);
    expect(await res.json()).toEqual({
      error: 'Idempotency-Key was already used with different arguments',
    });
  });

  it('reports an in-flight duplicate as 409 rather than running twice', async () => {
    mockPrisma.idempotencyKey.create.mockRejectedValue(conflict());
    mockPrisma.idempotencyKey.findUnique.mockResolvedValue({
      requestHash: requestHash({ a: 1 }),
      status: 0,
      response: null,
    });
    const handler = jest.fn();

    const res = await withIdempotency('k1', USER, 'cart:add', { a: 1 }, handler);

    expect(handler).not.toHaveBeenCalled();
    expect(res.status).toBe(409);
    expect(await res.json()).toEqual({
      error: 'A request with this Idempotency-Key is still in progress',
    });
  });

  it('releases the claim when the handler 500s, so a retry can retry', async () => {
    mockPrisma.idempotencyKey.create.mockResolvedValue({});
    const handler = jest
      .fn()
      .mockResolvedValue(NextResponse.json({ error: 'boom' }, { status: 500 }));
```

```ts
// app/api/v1/_lib/idempotency.ts
//
// Makes a mutating route safe to retry. A client that times out mid-request
// has no way to know whether the work happened; without this, its only
// options are to retry and risk doing it twice, or not to retry and risk
// not doing it at all.
//
// Database-backed rather than in-process, unlike the rate limiter next
// door. That one may forget its state on redeploy because forgetting a
// counter fails safe. Forgetting an idempotency key fails the other way:
// the retry executes a second cancellation.
import { createHash } from 'node:crypto';
import { NextResponse } from 'next/server';
import prisma from '@/lib/prisma';

// Sorted keys, so { a, b } and { b, a } are the same request. Anything
// else would let an argument reordering slip past the mismatch check.
function canonical(value: unknown): string {
  if (value === null || typeof value !== 'object') return JSON.stringify(value) ?? 'null';
  if (Array.isArray(value)) return `[${value.map(canonical).join(',')}]`;

  const entries = Object.entries(value as Record<string, unknown>)
    .filter(([, v]) => v !== undefined)
    .sort(([a], [b]) => (a < b ? -1 : a > b ? 1 : 0))
    .map(([k, v]) => `${JSON.stringify(k)}:${canonical(v)}`);

  return `{${entries.join(',')}}`;
}

export function requestHash(args: unknown): string {
  return createHash('sha256').update(canonical(args)).digest('hex');
}

const NO_STORE = { 'cache-control': 'no-store' } as const;

/**
 * Runs `handler` at most once per (user, scope, key).
 *
 * With no key the handler runs unguarded -- the storefront's own fetches
 * do not send one, and requiring it would be a breaking change to a
 * shipped API for the sake of a caller that does not exist yet.
 */
export async function withIdempotency(
  key: string | null,
  userId: string,
  scope: string,
  args: unknown,
  handler: () => Promise<NextResponse>
): Promise<NextResponse> {
  if (!key) return handler();

  const where = { userId_scope_key: { userId, scope, key } };
  const hash = requestHash(args);

  try {
    // Claim first. Two concurrent identical requests race here, and the
    // loser is told the work is in flight rather than doing it again.
    await prisma.idempotencyKey.create({
      data: { key, userId, scope, requestHash: hash, status: 0 },
    });
  } catch (error) {
    if ((error as { code?: string }).code !== 'P2002') throw error;

    const existing = await prisma.idempotencyKey.findUnique({ where });

    if (!existing) {
      // Vanished between the create and the read. Treat as in flight
      // rather than guessing.
      return NextResponse.json(
        { error: 'A request with this Idempotency-Key is still in progress' },
        { status: 409, headers: NO_STORE }
      );
    }

    // The binding that matters: a key approved for one request must not be
    // spent on a different one.
    if (existing.requestHash !== hash) {
      return NextResponse.json(
        { error: 'Idempotency-Key was already used with different arguments' },
        { status: 409, headers: NO_STORE }
      );
    }

    if (existing.status === 0) {
      return NextResponse.json(
        { error: 'A request with this Idempotency-Key is still in progress' },
        { status: 409, headers: NO_STORE }
      );
    }

    return NextResponse.json(existing.response as object, {
      status: existing.status,
      headers: { ...NO_STORE, 'idempotent-replay': 'true' },
    });
  }

  let response: NextResponse;
  try {
    response = await handler();
  } catch (error) {
    await prisma.idempotencyKey.delete({ where }).catch(() => undefined);
    throw error;
  }

  // A 5xx is not an outcome, it is an absence of one. Releasing the claim
  // is what makes the retry a retry rather than a permanent replay of a
  // server error.
  if (response.status >= 500) {
    await prisma.idempotencyKey.delete({ where }).catch(() => undefined);
    return response;
  }

  const body = await response.clone().json();
  await prisma.idempotencyKey.update({
    where,
    data: { status: response.status, response: body },
  });

  return response;
}
```

```python
"""The only thing in this service that speaks HTTP to /api/v1.

Every v1 response is `{"data": ...}` or `{"error": "..."}` with
`cache-control: no-store`. Unwrapping in one place means the tools deal in
values, and a change to the envelope breaks one file.

This client never re-implements a business rule. If a question can be
answered by the API -- may this be cancelled, is there stock -- it is
asked, not decided here.
"""

from typing import Any

import httpx

import config


class ApiError(Exception):
    """A non-2xx from /api/v1, carrying the status the agent should act on."""

    def __init__(self, status: int, message: str) -> None:
        super().__init__(f"{status}: {message}")
        self.status = status
        self.message = message


class EcommerceApi:
    def __init__(
        self,
        base_url: str | None = None,
        token: str | None = None,
        timeout: float | None = None,
    ) -> None:
        self.base_url = (base_url or config.ECOMMERCE_API_BASE_URL).rstrip("/")
        self.token = token
        self.timeout = timeout or config.HTTP_TIMEOUT_SECONDS

    def _headers(self, idempotency_key: str | None = None) -> dict[str, str]:
        headers = {"accept": "application/json"}
        if self.token:
            headers["authorization"] = f"Bearer {self.token}"
        if idempotency_key:
            headers["idempotency-key"] = idempotency_key
        return headers

    @staticmethod
    def _unwrap(response: httpx.Response) -> Any:
        try:
            body = response.json()
        except ValueError:
            # The body may be an HTML error page from a proxy. Reporting it
            # verbatim would put arbitrary upstream text into agent context.
            raise ApiError(response.status_code, "Upstream returned an unreadable response")

        if response.status_code >= 400:
            message = body.get("error") if isinstance(body, dict) else None
            raise ApiError(response.status_code, message or "Request failed")

        return body.get("data") if isinstance(body, dict) else body

    async def get(self, path: str, params: dict[str, Any] | None = None) -> Any:
        async with httpx.AsyncClient(timeout=self.timeout, cookies=None) as http:
            response = await http.get(
                f"{self.base_url}{path}",
                params={k: v for k, v in (params or {}).items() if v is not None},
                headers=self._headers(),
            )
        return self._unwrap(response)

    async def post(
        self,
        path: str,
        body: dict[str, Any],
        idempotency_key: str | None = None,
    ) -> Any:
        async with httpx.AsyncClient(timeout=self.timeout, cookies=None) as http:
            response = await http.post(
                f"{self.base_url}{path}",
                json=body,
                headers=self._headers(idempotency_key),
            )
        return self._unwrap(response)

    async def delete(self, path: str, params: dict[str, Any] | None = None) -> Any:
        async with httpx.AsyncClient(timeout=self.timeout, cookies=None) as http:
            response = await http.request(
                "DELETE",
                f"{self.base_url}{path}",
                params={k: v for k, v in (params or {}).items() if v is not None},
                headers=self._headers(),
            )
        return self._unwrap(response)

    async def whoami(self) -> dict[str, Any]:
        """The verified caller, as /api/v1 understands them.

        The MCP server has no other way to know: NextAuth mints an
        encrypted JWE, so the token is opaque to a Python process.
        """
        return await self.get("/api/v1/auth/whoami")
```

```python
"""Pydantic mirrors of the real /api/v1 response shapes.

Written against the routes, not against a description of them. Two things
follow from respond.ts and must not drift:

  - every money field arrives as a *string* ("10.50"), because a float
    would lose the scale the API deliberately preserved;
  - every timestamp arrives as an ISO 8601 string.

Extra fields are ignored rather than rejected: the API may grow a field
before this service knows about it, and a hard failure there would take
every tool down for an additive change.
"""

from pydantic import BaseModel, ConfigDict, Field


class Base(BaseModel):
    model_config = ConfigDict(populate_by_name=True, extra="ignore")


class ImageView(Base):
    url: str
    alt_text: str | None = Field(default=None, alias="altText")


class ProductSummary(Base):
    id: str
    name: str
    slug: str
    price: str
    compare_price: str | None = Field(default=None, alias="comparePrice")
    description: str | None = None
    status: str | None = None
    category_id: str | None = Field(default=None, alias="categoryId")
    images: list[ImageView] = Field(default_factory=list)


class Pagination(Base):
    page: int | None = None
    limit: int | None = None
    total: int | None = None
    pages: int | None = None


class ProductSearchResult(Base):
    products: list[ProductSummary] = Field(default_factory=list)
    pagination: Pagination | None = None


class InventoryView(Base):
    product_id: str = Field(alias="productId")
```

```python
import hashlib
import json


def _idempotency_key(operation: str, args: dict, request_id: str | None) -> str:
    """Stable for one logical call, different for a different one.

    Derived from the arguments rather than random so a retry of the *same*
    call reuses the key, while a genuinely different call cannot
    accidentally replay the previous result. `request_id` scopes it to one
    conversation turn, so "add one more" tomorrow is not a replay of "add
    one more" today.
    """
    payload = json.dumps(
        {"op": operation, "args": args, "request": request_id or ""}, sort_keys=True
    )
    return hashlib.sha256(payload.encode()).hexdigest()[:32]


async def add_to_cart(
    api: EcommerceApi,
    product_id: str,
    quantity: int,
    mode: str = "add",
    request_id: str | None = None,
) -> CartView:
    """Add to the caller's cart. Medium risk: executed, then surfaced.

    `mode='add'` increments an existing line, matching the storefront;
    `mode='set'` replaces the quantity. Over-stock comes back as 409 with
    the available count in the message.
    """
    body = {"productId": product_id, "quantity": quantity, "mode": mode}
    data = await api.post(
        "/api/v1/cart",
        body,
        idempotency_key=_idempotency_key("cart:add", body, request_id),
    )
    return CartView.model_validate(data)


async def remove_from_cart(
    api: EcommerceApi, product_id: str | None = None
) -> CartView:
    """Remove one product, or empty the cart when no product is named.

    Medium risk, by symmetry with add_to_cart: reversible, and the API
    scopes the delete to the caller's own cart id, so a product id can only
    ever reach their own lines.
    """
    return CartView.model_validate(
        await api.delete("/api/v1/cart", {"productId": product_id})
    )
```

```python
"""Approval tokens for high-risk tool calls.

Minted by non-LLM code -- the /approvals HTTP route in server.py, which is
deliberately not an MCP tool, so the agent cannot mint its own. In Phase 2
the chat UI calls it after a human presses a confirm button.

Every one of those five matters:

  - session, so an approval cannot cross conversations;
  - tool, so approval for one capability is not approval for another;
  - argument hash, so approval to cancel order #3 cannot be spent on #7 --
    this is the binding that presence-checking alone misses;

  - expiry, so a token left in a transcript goes stale.
"""

import base64
import hashlib
import hmac
import json
import secrets
import time

import config


class ApprovalError(Exception):
    """A high-risk call that may not proceed."""


# Spent nonces, in process. Single-replica only -- the same limitation the
# API's rate limiter documents. Unlike that one, this fails *safe* when
# forgotten: losing the set means a token could be replayed within its
# five-minute window, so the window is what keeps the exposure small.
# A shared store is required before this runs on more than one instance.
_spent: dict[str, float] = {}
_SWEEP_THRESHOLD = 1000


def reset_spent_nonces() -> None:
    """Test seam."""
    _spent.clear()


def _sweep(now: float) -> None:
    for nonce, expires in list(_spent.items()):
        if expires <= now:
            del _spent[nonce]


def _b64(raw: bytes) -> str:
    return base64.urlsafe_b64encode(raw).decode().rstrip("=")


def _unb64(value: str) -> bytes:
    return base64.urlsafe_b64decode(value + "=" * (-len(value) % 4))


def _encode(payload: dict) -> str:
    return _b64(json.dumps(payload, sort_keys=True, separators=(",", ":")).encode())


def args_hash(args: dict) -> str:
    """Canonical, so a reordering of the same arguments is the same call."""
    return hashlib.sha256(
        json.dumps(args, sort_keys=True, separators=(",", ":"), default=str).encode()
    ).hexdigest()


def _sign(body: str) -> str:
    return _b64(
        hmac.new(config.APPROVAL_SECRET.encode(), body.encode(), hashlib.sha256).digest()
    )


def mint(
    session_id: str,
    tool_name: str,
    args: dict,
    ttl_seconds: int | None = None,
) -> str:
    """Issue an approval. Never call this from a tool."""
    ttl = config.APPROVAL_TTL_SECONDS if ttl_seconds is None else ttl_seconds
    payload = {
        "sid": session_id,
        "tool": tool_name,
        "args": args_hash(args),
        "nonce": secrets.token_urlsafe(16),
        "exp": time.time() + ttl,
    }
    body = _encode(payload)
    return f"{body}.{_sign(body)}"


def validate(token: str, session_id: str, tool_name: str, args: dict) -> None:
    """Raise ApprovalError unless this exact call was approved.

    Validated against the arguments of the call actually arriving, not the
    ones the token was minted for -- those are only equal if nothing was
    swapped in between.
    """
    if not token or token.count(".") != 1:
        raise ApprovalError("Approval token is malformed")

    body, signature = token.split(".")

    if not hmac.compare_digest(signature, _sign(body)):
        raise ApprovalError("Approval token signature is invalid")

    try:
        payload = json.loads(_unb64(body))
    except Exception:
        raise ApprovalError("Approval token is malformed")

    now = time.time()

    if float(payload.get("exp", 0)) < now:
        raise ApprovalError("Approval token has expired")

    if payload.get("sid") != session_id:
        raise ApprovalError("Approval token belongs to another session")

    if payload.get("tool") != tool_name:
        raise ApprovalError("Approval token was issued for a different tool")

    if payload.get("args") != args_hash(args):
        raise ApprovalError("Approval token was issued for different arguments")

    nonce = payload.get("nonce", "")
    if nonce in _spent:
        raise ApprovalError("Approval token has already been used")

    if len(_spent) > _SWEEP_THRESHOLD:
        _sweep(now)

    _spent[nonce] = float(payload["exp"])
```

```python
import hashlib
import json

import approvals


async def cancel_order(
    api: EcommerceApi,
    order_id: str,
    session_id: str,
    approval_token: str | None,
) -> dict:
    """Cancel an order. **High risk** -- enforced, not merely conventional.

    The approval is checked before anything leaves this process. An agent
    that has been prompt-injected into calling this cannot proceed by
    intending to: without a token minted for this session, this tool, and
    this order id, the call does not happen.

    Whether the order *may* be cancelled is not decided here. cancelOrderFor
    owns that rule and answers 409 when it says no.
    """
    approvals.validate(approval_token or "", session_id, "cancel_order", {"order_id": order_id})

    # Derived from the order and the approval, so a network retry replays
    # rather than cancelling twice.
    key = hashlib.sha256(
        json.dumps({"op": "order:cancel", "id": order_id, "sid": session_id}, sort_keys=True).encode()
    ).hexdigest()[:32]

    return await api.post(f"/api/v1/orders/{order_id}/cancel", {}, idempotency_key=key)
```

```python
"""The MCP server.

HTTP transport with per-request auth, deliberately not stdio: a stdio
process carries one ambient identity, and this is a multi-user app. Every
tool call resolves its caller from the Authorization header of the request
that carried it.

The tools here are thin. Everything they do is in tools/*.py, which is
also the split Phase 3 uses to hand each file to a specialist agent.
"""

from typing import Any

from fastmcp import FastMCP
from fastmcp.server.dependencies import get_http_headers

import approvals
import config
from clients.ecommerce_api import EcommerceApi
from tools import cart as cart_tools
from tools import orders as order_tools
from tools import products as product_tools

mcp = FastMCP("mcp-ecom")


class MissingCredential(Exception):
    """The request carried no usable identity."""


def api_for_headers(headers: dict[str, str]) -> EcommerceApi:
    """One client per request, carrying that request's token.

    Never cached and never shared: a client held between requests is an
    ambient identity by another name.
    """
    header = headers.get("authorization", "")
    scheme, _, value = header.partition(" ")

    if scheme.lower() != "bearer" or not value.strip():
        raise MissingCredential("A bearer token is required")

    return EcommerceApi(token=value.strip())


def session_id_for_headers(headers: dict[str, str]) -> str:
    """The conversation an approval is scoped to.

    Refused rather than defaulted: one shared default would put every
    caller in the same approval scope, which is the failure the binding
    exists to prevent.
    """
    session = headers.get("mcp-session-id", "").strip()
    if not session:
        raise MissingCredential("A session id is required")
    return session


def _request_api() -> EcommerceApi:
    return api_for_headers(get_http_headers())


@mcp.tool
async def search_products(
    query: str = "",
    limit: int | None = None,
    page: int | None = None,
    category: str | None = None,
    min_price: float | None = None,
    max_price: float | None = None,
    min_rating: float | None = None,
) -> Any:
    """Search the product catalogue by keyword, category, price or rating."""
    result = await product_tools.search_products(
        _request_api(),
        query=query,
        limit=limit,
        page=page,
        category=category,
        min_price=min_price,
        max_price=max_price,
        min_rating=min_rating,
    )
    return result.model_dump(by_alias=True)


@mcp.tool
async def get_product(product_id: str) -> Any:
    """Full detail for one product."""
    return (await product_tools.get_product(_request_api(), product_id)).model_dump(by_alias=True)


@mcp.tool
async def check_inventory(product_id: str) -> Any:
    """Current stock for one product. Never cached."""
    return (await product_tools.check_inventory(_request_api(), product_id)).model_dump(by_alias=True)


@mcp.tool
async def get_orders(limit: int | None = None) -> Any:
    """The signed-in customer's orders, newest first."""
    orders = await order_tools.get_orders(_request_api(), limit=limit)
    return [order.model_dump(by_alias=True) for order in orders]


@mcp.tool
async def get_order(order_id: str) -> Any:
    """One of the signed-in customer's orders."""
    return (await order_tools.get_order(_request_api(), order_id)).model_dump(by_alias=True)


@mcp.tool
async def get_cart() -> Any:
    """The signed-in customer's cart, with item count and subtotal."""
    return (await cart_tools.get_cart(_request_api())).model_dump(by_alias=True)

async def add_to_cart(product_id: str, quantity: int, mode: str = "add") -> Any:
    """Add a product to the cart. 'add' increments, 'set' replaces."""
    headers = get_http_headers()
    view = await cart_tools.add_to_cart(
        api_for_headers(headers),
        product_id=product_id,
        quantity=quantity,
        mode=mode,
        request_id=headers.get("mcp-session-id"),
    )
    return view.model_dump(by_alias=True)

async def remove_from_cart(product_id: str | None = None) -> Any:
    """Remove one product from the cart, or empty it when none is named."""
    return (
        await cart_tools.remove_from_cart(_request_api(), product_id=product_id)
    ).model_dump(by_alias=True)


@mcp.tool
async def cancel_order(order_id: str, approval_token: str | None = None) -> Any:
    """Cancel an order. Requires an approval token issued for this exact order.

    The token is not something to invent or reuse: it is minted only by the
    confirmation flow, for one order, once.
    """
    headers = get_http_headers()
    return await order_tools.cancel_order(
        api_for_headers(headers),
        order_id=order_id,
        session_id=session_id_for_headers(headers),
        approval_token=approval_token,
    )


def registered_tool_names() -> list[str]:
    """The tool surface, for the test that asserts what is exposed."""
    import asyncio

    return list(asyncio.run(mcp.get_tools()).keys())


@mcp.custom_route("/approvals", methods=["POST"])
async def mint_approval(request):  # pragma: no cover - exercised in Task 11
    """Mint an approval token. **Not an MCP tool, deliberately.**

    An agent that can call this can approve itself, which would make the
    whole mechanism theatre. It lives on the HTTP surface so that the
    Phase 2 chat UI -- non-LLM code, behind a human pressing a button --
    can call it, and the agent's MCP connection cannot.
    """
    from starlette.responses import JSONResponse

    headers = {k.lower(): v for k, v in request.headers.items()}

    try:
        api_for_headers(headers)
        session = session_id_for_headers(headers)
    except MissingCredential as error:
        return JSONResponse({"error": str(error)}, status_code=401)

    body = await request.json()
    tool = body.get("tool")
    args = body.get("args") or {}

    if tool != "cancel_order":
        return JSONResponse({"error": "Unknown high-risk tool"}, status_code=400)

    return JSONResponse(
        {
            "token": approvals.mint(session, tool, args),
            "expiresIn": config.APPROVAL_TTL_SECONDS,
        }
    )


if __name__ == "__main__":
    mcp.run(transport="http", host="0.0.0.0", port=config.PORT)
```

```python
"""Exercise every tool through a bare MCP client, with no agent involved.

This is what isolates "is it the MCP layer or the agent" when something
breaks in Phase 2. It also produces the per-tool latency floor.

Queries are varied on purpose: searchProducts sits behind a 300-second
unstable_cache, so repeating one term measures the cache, not the system.
An agent issuing real queries will not see those numbers.

  python scripts/sweep.py --url http://localhost:8000/mcp \\
      --api https://web-production-bb55d.up.railway.app \\
      --email demo@example.com --password '...'
"""

import argparse
import asyncio
import json
import time
from pathlib import Path

import httpx
from fastmcp import Client

TERMS = ["shoes", "iphone", "shirt", "laptop", "headphones", "cotton", "galaxy", "air"]
SAMPLES = 8


def percentile(values: list[float], p: float) -> int:
    if not values:
        return 0
    ordered = sorted(values)
    index = min(len(ordered) - 1, max(0, int((p / 100) * len(ordered) + 0.999) - 1))
    return round(ordered[index])


async def get_token(api: str, email: str, password: str) -> str:
    async with httpx.AsyncClient(timeout=20) as http:
        response = await http.post(
            f"{api}/api/v1/auth/token",
            json={"email": email, "password": password, "ttlSeconds": 900},
        )
        response.raise_for_status()
        return response.json()["data"]["token"]


async def mint_approval(url: str, token: str, session: str, order_id: str) -> str:
    base = url.rsplit("/mcp", 1)[0]
    async with httpx.AsyncClient(timeout=20) as http:
        response = await http.post(
            f"{base}/approvals",
            json={"tool": "cancel_order", "args": {"order_id": order_id}},
            headers={"authorization": f"Bearer {token}", "mcp-session-id": session},
        )
        response.raise_for_status()
        return response.json()["token"]


async def timed(client: Client, name: str, args: dict) -> tuple[float, bool]:
    started = time.perf_counter()
    try:
        await client.call_tool(name, args)
        return (time.perf_counter() - started) * 1000, True
    except Exception as error:  # noqa: BLE001 - a failure is a data point
        print(f"    {name} failed: {error}")
        return (time.perf_counter() - started) * 1000, False


async def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--url", required=True)
    parser.add_argument("--api", required=True)
    parser.add_argument("--email", required=True)
    parser.add_argument("--password", required=True)
    parser.add_argument("--out", default="../web/metrics/mcp-latency.json")
    args = parser.parse_args()

    token = await get_token(args.api, args.email, args.password)
    session = f"sweep-{int(time.time())}"
    headers = {"authorization": f"Bearer {token}", "mcp-session-id": session}

    results: dict[str, dict] = {}

    async with Client(args.url, headers=headers) as client:
        tools = {tool.name for tool in await client.list_tools()}
        print(f"  tools advertised: {len(tools)}")

        product = None
        order = None

        # Reads first, so the write cases have a real product and order to
        # work with rather than invented ids.
        for index in range(SAMPLES):
            term = TERMS[index % len(TERMS)]
            elapsed, ok = await timed(client, "search_products", {"query": term, "limit": 5})
            results.setdefault("search_products", {"timings": [], "ok": 0, "n": 0})
            results["search_products"]["timings"].append(elapsed)
            results["search_products"]["ok"] += int(ok)
            results["search_products"]["n"] += 1

        found = await client.call_tool("search_products", {"query": "", "limit": 1})
        payload = json.loads(found.content[0].text)
        if payload.get("products"):
            product = payload["products"][0]["id"]

        cases: list[tuple[str, dict]] = [
            ("get_product", {"product_id": product}),
            ("check_inventory", {"product_id": product}),
            ("get_orders", {"limit": 5}),
            ("get_cart", {}),
            ("add_to_cart", {"product_id": product, "quantity": 1}),
            ("remove_from_cart", {"product_id": product}),
        ]

        for name, call_args in cases:
            for _ in range(SAMPLES):
                elapsed, ok = await timed(client, name, call_args)
                results.setdefault(name, {"timings": [], "ok": 0, "n": 0})
                results[name]["timings"].append(elapsed)
                results[name]["ok"] += int(ok)
                results[name]["n"] += 1

        orders_result = await client.call_tool("get_orders", {"limit": 5})
        placed = json.loads(orders_result.content[0].text)
        cancellable = [o for o in placed if o["status"] in ("PENDING", "PROCESSING")]

        # The security assertion, run against the live server: a high-risk
        # call with no approval must fail even though the caller is fully
        # authenticated and owns the order.
        if cancellable:
            order = cancellable[0]["id"]
            try:
                await client.call_tool("cancel_order", {"order_id": order})
                raise SystemExit("FAIL: cancel_order succeeded without an approval token")
            except SystemExit:
                raise
            except Exception:
                print("  cancel_order without approval: refused (correct)")

            approval = await mint_approval(args.url, token, session, order)
            elapsed, ok = await timed(
                client, "cancel_order", {"order_id": order, "approval_token": approval}
            )
            results["cancel_order"] = {"timings": [elapsed], "ok": int(ok), "n": 1}
        else:
            print("  no cancellable order; place one before sweeping cancel_order")

    summary = {
        name: {
            "p50": percentile(data["timings"], 50),
            "p95": percentile(data["timings"], 95),
            "successRate": round(data["ok"] / data["n"], 3),
        }
        for name, data in results.items()
    }

    out = Path(args.out)
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_text(json.dumps(summary, indent=2) + "\n")

    for name, timing in summary.items():
        print(f"  {name:20} p50 {timing['p50']:>5}ms  p95 {timing['p95']:>5}ms  ok {timing['successRate']}")


if __name__ == "__main__":
    asyncio.run(main())
```

## Risks Carried Out Of M3

Not blockers for this milestone. Each one has to be someone's problem before this is more than a demo.

- **Prompt injection via tool output is unmitigated.** `Review.content`, `Review.title` and product descriptions are attacker-controllable text that flows into agent context through low-risk tools. Approval tokens close the *execution* path; they do nothing about exfiltration. **Owner: a design pass before Phase 2 ships.**
- **The spent-nonce set is per-process.** Single-use approval holds for one replica. Scale the `mcp` service and a token becomes replayable within its TTL.
- **Idempotency keys are never garbage-collected.** The table grows without bound. A retention sweep is a small follow-up, not a correctness issue at demo volume.
- **Session JWTs still have no revocation.** Task 2 shortens the window; it does not add a kill switch. Rotating `NEXTAUTH_SECRET` still signs out every browser.
- **API rate limiting remains per-instance and in-process**, and now has a second caller hitting it.
- **83 npm advisories, 4 critical**, inherited upstream and untouched by this milestone.
